Ejercicio 1:

Elabore un formulario que solicite el nombre del usuario y envíe la información a otro archivo PHP donde se muestre un mensaje de bienvenida con el nombre ingresado.




Ejercicio 2:

Elabore un formulario que solicite dos números y que envíe los datos a otro archivo PHP donde se muestre el resultado de la suma.




Ejercicio 3:

Diseñe un formulario que permita ingresar dos números y envíe la información a otro archivo PHP para mostrar el resultado de la resta.




Ejercicio 4:

Cree un formulario que solicite dos números y envíe los datos a otro archivo PHP donde se calcule y muestre la multiplicación.




Ejercicio 5:

Realice un formulario que permita ingresar dos números y envíe los datos a otro archivo PHP donde se muestre el resultado de la división.




Ejercicio 6:

Elabore un formulario que solicite el nombre y la edad de una persona y envíe la información a otro archivo PHP donde se muestren ambos datos.




Ejercicio 7:

Diseñe un formulario que solicite dos números y envíe los datos a otro archivo PHP donde se determine y muestre cuál número es mayor.




Ejercicio 8:

Cree un formulario que permita ingresar dos números y envíe la información a otro archivo PHP donde se indique cuál es el número menor.




Ejercicio 9:

Elabore un formulario que solicite un número entero y envíe el dato a otro archivo PHP donde se determine si el número es par o impar.




Ejercicio 10:

Diseñe un formulario que solicite tres notas de un estudiante y envíe la información a otro archivo PHP donde se calcule y muestre el promedio.




Ejercicio 11:

Cree un formulario que solicite tres notas de un estudiante y envíe los datos a otro archivo PHP donde se calcule el promedio y se indique si el estudiante aprobó o reprobó.




Ejercicio 12:

Elabore un formulario que solicite la base y la altura de un rectángulo y envíe los datos a otro archivo PHP donde se calcule y muestre el área.




Ejercicio 13:

Diseñe un formulario que solicite el valor de un lado de un cuadrado y envíe la información a otro archivo PHP donde se calcule el perímetro.




Ejercicio 14:

Cree un formulario que permita ingresar una cantidad en metros y envíe el dato a otro archivo PHP donde se convierta y muestre la cantidad en centímetros.




Ejercicio 15:

Elabore un formulario que solicite una temperatura en grados Celsius y envíe la información a otro archivo PHP donde se realice la conversión a grados Fahrenheit.




Ejercicio 16:

Diseñe un formulario que solicite el nombre del empleado, las horas trabajadas y el pago por hora. Los datos deben enviarse a otro archivo PHP donde se calcule y muestre el salario total.




Ejercicio 17:

Cree un formulario que solicite el monto total de una compra y envíe la información a otro archivo PHP donde se aplique un descuento del 10% si la compra supera cierta cantidad.




Ejercicio 18:

Elabore un formulario que solicite el nombre del cliente, el producto, la cantidad y el precio unitario. En otro archivo PHP deberá mostrarse una factura con el subtotal y el total a pagar.




Ejercicio 19:

Diseñe un formulario que solicite un número y envíe el dato a otro archivo PHP donde se muestre la tabla de multiplicar del 1 al 10.




Ejercicio 20:

Cree un formulario que permita ingresar un número y envíe el dato a otro archivo PHP donde se realice la suma de los números desde 1 hasta el número ingresado.




Ejercicio 21:

Elabore un formulario que solicite una palabra y envíe la información a otro archivo PHP donde se muestre la cantidad de letras que contiene la palabra ingresada.




Ejercicio 22:

Diseñe un formulario que solicite una cantidad en dólares y envíe la información a otro archivo PHP donde se realice la conversión a euros.




Ejercicio 23:

Cree un formulario que solicite el precio de un producto y envíe el dato a otro archivo PHP donde se calcule y muestre el total con IVA incluido.




Ejercicio 24:

Elabore un formulario que solicite la edad actual de una persona y envíe la información a otro archivo PHP donde se muestre la edad que tendrá dentro de 10 años.




Ejercicio 25:

Diseñe un formulario que solicite nombre, correo electrónico y ciudad del usuario. Los datos deben enviarse a otro archivo PHP donde se muestre toda la información ingresada.
